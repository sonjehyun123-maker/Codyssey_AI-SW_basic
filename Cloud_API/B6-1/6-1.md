AWS?(Amazon web service)
- 예전에는 서비스를 만들려면 직접 서버를 구축하고 네트워크, 전기연결 모든것을 다 해야했음.
- AWS는 인터넷 어닌가에 서버를 만들고 구축할 수 있게함.
- AWS에서 직접 해야하는것 >> 접속자, 네트워크 종류, 보안 등 


* 루트 계정 : 어떤 것이든 할 수 있음(평소에는 쓰지않음 - 보안 위험(B1-1))
* IAM사용자 : 루트가 만들어낸 부계정. 권한을 제한해 보안 방지
* 리전 : 서버가 위치할 지역

```
[재현 노트북] ──인터넷──> [AWS에 있는 재현의 서버(EC2)]
```

"이 서버를 만들고, 켜고, 끄고, 설정 바꿀 수 있는 사람이 누구냐" → 이게 IAM
"이 서버에 실제로 접속(트래픽)할 수 있는 통로는 어디냐" → 이게 Security Group(SG)


IAM??
- 서버(EC2) 제작/삭제 , 네트워크(VPC) 설정 바꾸기, SG규칙 추가/삭제 드 ㅇ
- 서버에서 사용 할 수 있는 권한
