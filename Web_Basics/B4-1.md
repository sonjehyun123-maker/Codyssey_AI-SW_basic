# 웹 기초 완성, 나만의 포트폴리오 사이트

순수 HTML/CSS/JavaScript로 제작한 반응형 개발자 포트폴리오입니다.

## 폴더 구조
```
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
│   └── profile.jpg   (본인 사진으로 교체)
└── README.md
```

## 주요 기능
- **반응형 레이아웃**: 모바일(~767px) / 태블릿(768px~) / 데스크톱(1024px~) 대응
- **다크 모드**: 토글 클릭 시 테마 전환, `localStorage`에 저장되어 새로고침 후에도 유지
- **햄버거 메뉴**: 모바일에서 `classList.toggle('active')`로 열고 닫기
- **부드러운 스크롤 + 스크롤 탑 버튼**: 300px 이상 스크롤 시 버튼 노출
- **네비게이션 스타일 변경**: 60px 이상 스크롤 시 헤더 배경 활성화
- **스크롤 애니메이션**: Intersection Observer, `threshold: 0.2`
- **GitHub API 연동**: 로딩 / 성공 / 에러(재시도 버튼) / 빈 상태 UI 구현
- **폼 유효성 검사**: 필수값 검증 + 이메일 정규식 검증, 필드별 에러 메시지 표시

## 상태 → 렌더링 흐름
1. 다크 모드 토글 → 테마 상태 변경 → `data-theme` 속성 및 전체 스타일 변경
2. GitHub API 호출 → 로딩/성공/에러 상태 변경 → Projects 섹션 렌더링
3. 폼 입력 → 유효성 상태 변경 → 필드별 에러 메시지 표시/숨김

## 로컬 실행
1. VS Code에서 프로젝트 폴더 열기
2. Live Server 확장 설치 후 `index.html` 우클릭 → "Open with Live Server"

## GitHub API 참고
- 인증 없이 호출 시 시간당 60회 제한(rate limit)이 있습니다.
- 403 응답 발생 시 에러 상태 UI(재시도 버튼)가 표시됩니다.
- `js/main.js`의 `GITHUB_USERNAME` 상수를 본인 GitHub 아이디로 설정하면 됩니다. (현재: `sonjehyun123-maker`)
